Метод	Описание	Пример
toString(array)	Преобразует массив в строку	"[1, 2, 3]"
sort(array)	Сортирует массив по возрастанию	[1, 2, 3, 5, 8, 9]
binarySearch(array, key)	Бинарный поиск (массив должен быть отсортирован)	индекс или отрицательное число
equals(arr1, arr2)	Сравнивает два массива	true или false
compare(arr1, arr2)	Лексикографическое сравнение	-1, 0, 1
fill(array, value)	Заполняет массив значением	[42, 42, 42]
copyOf(array, length)	Копирует массив	новый массив
copyOfRange(array, from, to)	Копирует диапазон	новый массив
