byte b = a + 10; → Ошибка компиляции
a имеет тип int, 10 - int. Результат a + 10 = int.
Нельзя автоматически присвоить int в byte (сужающее преобразование).

byte c = (byte)(a + 10); → c = -126
a + 10 = 130 (int).
(byte) сужает до диапазона -128..127.
130 - 256 = -126.

byte d = a + 1; → Ошибка компиляции
Та же причина: int в byte без явного приведения.
